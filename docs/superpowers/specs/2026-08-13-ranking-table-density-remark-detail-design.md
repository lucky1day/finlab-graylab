# 候选方案排行表密度与备注详情设计

## 目标

在不改变前端业务逻辑、Dashboard API 契约、筛选、排序、指标计算或方案选择语义的前提下，优化“当前任务格子方案排行”的信息密度与备注阅读体验。

本次仅修改排行表的展示层：

- 压缩“样本数”“上涨准确率”“下跌准确率”“来源”四列的宽度与横向留白；
- 保留完整的九列表格结构；
- 将备注单元格从两行截断文本改为紧凑的“详情”入口；
- 点击“详情”后，以局部轻浮层展示该行现有的完整备注；
- 微调排行表的对齐、间距和交互状态，使信息层级更清晰。

## 明确不变的范围

“区间准确率”整列是禁止变动区域，必须逐项保留当前实现：

- 表头仍为现有可点击的排序按钮；
- 当前排序方向仍由现有 `data-sort-direction` 和伪元素显示，例如 `DESC`；
- 单元格继续显示 `68.1%（262/385）` 形式的百分比与命中数；
- 继续显示现有绿色准确率进度条；
- 现有指标颜色、排序行为和 hover 状态不变；
- 不修改 `renderSchemeRanking()` 的排序、指标选择或方案选择逻辑。

以下内容同样不在本次范围内：

- Dashboard API、字段解码和数据模型；
- 月份、数据来源、排序指标筛选；
- 任务格子、月度指标和趋势图；
- 方案备注文本的生成规则；
- 任何 backend、数据库或 launchd 配置。

## 最终布局

排行表继续保留九列：

1. 排名
2. 方案
3. 区间准确率
4. 样本数
5. 上涨准确率
6. 下跌准确率
7. 部署时间
8. 来源
9. 备注

宽度调整只针对用户指定的四列：

- 样本数：从当前 `120px` 收紧到约 `82px`；
- 上涨准确率：从当前 `140px` 收紧到约 `112px`；
- 下跌准确率：从当前 `140px` 收紧到约 `112px`；
- 来源：从当前占用剩余大宽度改为约 `84px`；
- 备注列使用释放出的空间，并保留约 `96px` 的详情入口区域；
- 区间准确率继续使用当前 `180px`，不调整；
- 部署时间继续使用当前 `120px`，不调整。

表头与数值列使用更一致的居中对齐；方案名继续允许两行截断。表格仍保留横向滚动作为窄屏的最终兜底，不通过缩小字体挤压内容。

## 备注详情交互

备注单元格显示一个带信息图标的原生按钮，文字为“详情”。按钮只负责展示当前行已经存在的完整备注，不改变行选择或方案选择。

点击后打开靠近按钮的局部轻浮层：

- 桌面端最大宽度约 `440px`；
- 标题栏显示“方案备注”和关闭按钮；
- 正文使用正常可读字号与行距，建议 `14px / 1.75`；
- 正文自然换行，不做两行截断；
- 正文最大高度约 `190px`，只有更长内容才在浮层内部滚动；
- 不使用全屏遮罩，不改变表格行高；
- 点击关闭按钮、浮层外部或按 `Escape` 均可关闭；
- 任一时刻只显示一条备注；点击另一行详情时切换内容；
- 窄屏下宽度贴合可视区域，保持左右安全间距，不超出视口。

浮层使用 `role="dialog"`、可关联标题，并在打开时把焦点移入关闭按钮；关闭后焦点返回原“详情”按钮。交互使用原生按钮，不以 `title` tooltip 作为主要阅读入口。

## 事件边界

排行行本身已有点击选择方案的行为。详情按钮必须阻止其点击事件冒泡，避免打开备注时同时改变选中方案。

新增展示状态只保存：

- 当前打开备注所属的方案 ID；
- 触发按钮引用，用于关闭后的焦点恢复。

该状态不进入 Dashboard 数据状态、不参与排序，也不持久化到 URL、localStorage 或后端。

## 验证

先新增前端静态契约测试，验证：

- 九列表头完整保留；
- 区间准确率仍使用现有排序按钮、百分比/命中数和进度条结构；
- 指定四列的宽度被收紧，区间准确率与部署时间宽度未变；
- 每个排行行仍渲染九个单元格；
- 备注单元格渲染原生“详情”按钮，而不是截断的完整备注文本；
- 页面包含单一、可访问的备注详情浮层；
- 详情按钮阻止行点击冒泡，支持关闭按钮、外部点击和 `Escape`。

实现完成后运行：

- 前端排行与 owner 列相关定向测试；
- 前端 asset hash、Dashboard 契约和 dashboard gate 测试；
- 完整 `pytest`；
- 浏览器桌面宽度验收：区间准确率外观与行为不变、四列更紧凑、备注可读且不产生大面积遮挡；
- 浏览器窄屏验收：表格允许横向滚动、详情浮层不超出可视区域；
- 键盘验收：Tab 可到达详情按钮、`Escape` 可关闭、焦点可恢复。

## 成功标准

- 排行表信息密度提升，指定四列明显收紧；
- 区间准确率当前展示逐项不变；
- 完整备注可通过清晰的“详情”入口阅读；
- 浮层不会形成全屏或大面积遮挡，长文本仍清晰可读；
- 不改变任何数据、指标、筛选、排序或选择逻辑；
- 自动化测试和桌面/窄屏浏览器验收全部通过。
