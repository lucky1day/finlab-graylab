# Bond Factor Lab 灰度实验室说明手册

**文档状态**：`CURRENT`

**目标读者**：外部客户、业务负责人、合作方

**文档定位**：页面使用与结果解释；技术口径以[预测语义](../architecture/PREDICTION_SEMANTICS.md)和[Dashboard 合同](../operations/PUBLIC_FACTOR_LAB_PERFORMANCE.md)为准。

## 1. 灰度实验室定位

Bond Factor Lab 灰度实验室是一个国债因子方案的回测与实盘观察平台。它用于把不同预测方案放在统一任务格子下比较，展示回测与实盘的预测方向、验证结果及准确率指标。

页面中的“涨 / 跌 / 平”指目标国债活跃收益率方向。“平”和待验证如何计入统计见下文指标口径。

## 2. 页面功能导览

灰度实验室前端以“任务格子”为主线组织信息。一个任务格子由 `Y 标的 + 任务类型` 定义，例如 `10Y国债活跃 · 周收盘` 或 `5Y国债活跃 · 季均`。

### 2.1 任务格子矩阵

矩阵行是国债期限标的，当前包括 `1Y / 3Y / 5Y / 7Y / 10Y`。矩阵列是任务类型：

| 列 | 含义 |
|---|---|
| `T+1` | 预测下一交易日收益率方向 |
| `T+5` | 预测后续第五个交易日收益率方向 |
| `周收盘` | 预测下一周关键观察点方向 |
| `周平均` | 预测下一周平均收益率相对当前周平均的方向 |
| `月中收` | 预测下月观察点相对本月观察点的方向 |
| `月均` | 预测下一 MID 月中桶平均收益率相对当前桶平均收益率的方向 |
| `季均` | 预测下一自然季度平均收益率相对当前季度平均收益率的方向 |
| `年均` | 预测下一春节年平均收益率相对当前春节年平均收益率的方向 |

每个格子展示该任务下的最优指标和候选方案数量；标题栏“方案总数”是全部任务格子候选方案数量之和，不随月份或回测/实盘筛选变化。点击格子后，下方排行与详情会切换到对应任务。

### 2.2 筛选与排行

页面支持按数据来源和月份区间筛选：

- `回测+实盘(全部)`：合并展示历史回测和实盘观察。
- `仅回测`：只看历史复现结果。
- `仅实盘`：只看按产品日期分界归入实盘的记录。

排行可以按整体准确率、上涨准确率或下跌准确率排序。候选方案表展示排名、方案名称、区间准确率、样本数、上涨/下跌准确率、部署时间、来源和说明。“来源”表示方案提供者。准确率括号的解释见[指标口径](#3-指标口径)。

方案名称右侧的深绿色菱形表示该方案被运维名单标记为生产方案；它不改变排行、统计或执行资格，也不证明自然运行已完成验收。标记依据见[Dashboard 合同](../operations/PUBLIC_FACTOR_LAB_PERFORMANCE.md#生产方案标记)。

### 2.3 方案详情

选中方案后，月度表展示样本数、实际/预测方向分布、准确率与召回率，并提供逐点明细入口。

趋势图展示所选方案在各月份的指标变化。在“全部”口径下，页面会在回测与实盘的交界处插入“实盘”分隔线，避免把历史回测和实盘观察混为同一段。

### 2.4 每日 / 周度验证明细

点击月度表中的日历按钮，查看预测日、目标日/周、预测方向、实际方向和验证结果。

首屏只加载按月汇总。逐日/逐周记录在点击具体月份后按方案、月份和当前数据源筛选即时加载；加载失败只在
明细抽屉显示错误和重试入口，不清空已经展示的排行与趋势，也不会用旧明细冒充本次结果。

结果列的含义：

| 展示 | 含义 |
|---|---|
| `✓` | 有方向预测，且与实际方向一致 |
| `×` | 有方向预测，但与实际方向不一致 |
| `-` | 预测为“平”，不进入准确率分母 |
| `?` 或待验证 | 目标实际值尚未覆盖，暂不计入准确率 |

“待验证”表示目标实际值尚未覆盖，不代表预测失败或刷新异常。某月全部待验证时仍可打开明细，样本数为 0、准确率为 `--`。

## 3. 指标口径

灰度实验室把“展示样本数”和“准确率分母”明确分开。

| 名称 | 含义 |
|---|---|
| 样本数 | 已经可评价的预测记录总数，包含预测为“涨 / 跌 / 平”的记录 |
| 指标分母 | 只包含预测为“涨”或“跌”的方向样本，不包含“平” |
| 正确数 | 在指标分母内，预测方向与实际方向一致的样本数 |
| 整体准确率 | `正确数 / 指标分母` |
| 上涨准确率 | 预测为上涨的样本中，实际也上涨的比例 |
| 上涨召回率 | 实际上涨的样本中，被预测为上涨的比例 |
| 下跌准确率 | 预测为下跌的样本中，实际也下跌的比例 |
| 下跌召回率 | 实际下跌的样本中，被预测为下跌的比例 |

例如某月共有 8 条已验证样本，其中 1 条预测为“平”，3 条方向预测正确，4 条方向预测错误，则页面展示：

- 样本数：`8`
- 整体准确率：`3/7`

指标定义以[预测语义](../architecture/PREDICTION_SEMANTICS.md#6-指标统计口径)为准；本表用于解释页面。

## 4. 日期与结果分类

| 页面日期 | 含义 |
|---|---|
| 预测日 | 信号发出日；回测中是历史站位日 |
| 数据截止日 | 模型允许使用数据的截止时点 |
| 目标日/目标周 | 预测验证的目标；用于关联实际方向和结果分类 |

页面只展示“回测”和“实盘”两种结果类型，分界按[预测语义](../architecture/PREDICTION_SEMANTICS.md#7-前端展示规则)定义的目标日期判断。页面中的实盘记录不能单独证明该预测由自然调度发出，运行来源需由运维核对真实调度记录。

周期均值预测的是下一个完整业务桶，而非一天：月均使用月中桶，季均使用自然季度，年均使用春节年。目标日期是定位桶的日期指针，不能据此认为均值已经能够验证；目标桶的实际数据齐备后才参与统计。具体桶与月份映射见[预测语义](../architecture/PREDICTION_SEMANTICS.md)。

## 5. 登录、权限与页面状态

页面需要登录，账户菜单提供退出和改密；具有相应权限的管理员可以管理用户。账户操作与预测展示权限分开，详细规则见[认证与账户管理](../architecture/AUTHENTICATION_AND_ACCOUNT_MANAGEMENT.md)。

预测与指标只读，用户不能在页面触发算法、激活方案或修改预测/Actual。浏览器能够读取已展示的数据；只读权限不等于加密隐藏展示结果。

页面只展示已激活方案，方案显示的部署时间不证明定时任务已经安装或完成自然运行。具体上线状态与证据由[当前状态](../CURRENT_STATUS.md)定位。

首次读取失败时页面显示不可用；刷新失败但已有成功结果时，保留完整旧视图并标明上次成功时间及过期状态。具体月份的明细错误与重试见[明细说明](#24-每日--周度验证明细)。

## 6. 如何读一个任务格子：示例

以 `10Y国债活跃 · 周收盘` 为例：

1. 点击 `10Y` 行、`周收盘` 列，选择月份区间和回测/实盘口径。
2. 查看排行的区间准确率与样本数，再选中方案查看月度变化；小样本不能单独支撑稳定表现结论。
3. 点击具体月份的日历按钮，核对逐点方向和结果；按上文区分“平”、待验证与错误，结合目标时点解读。
4. 对比跨回测/实盘的区间时保留分段说明，不把不同执行口径混称。

## 7. 对外解读

本平台用于观察和比较预测，不构成交易指令、投资建议或收益承诺。回测表现、技术验收或方案激活不能等同于未来收益或自然运行已验证。

报告结果时同时说明任务格子、回测/实盘口径、月份区间、样本数与指标分母，以及是否存在待验证样本。跨过回测与实盘分隔线时分别解释两段结果，不能将不同输入或执行口径的结果宣称为算法等价证据。

访问问题见[部署访问](../operations/DEPLOYMENT_ACCESS.md)，刷新故障见[Dashboard 合同与运行验收](../operations/PUBLIC_FACTOR_LAB_PERFORMANCE.md)。
