## 环境

所有入口都会加载：

```bash
scripts/forecast_env.sh
```

关键默认值：

- `DRY_RUN=0`
- `CONDA_ENV_NAME=forecast_env`
- `PYTHON_BIN=$VENV_PATH/bin/python`

数据输入规则：

- 默认运行只从数据库构建日、周、月宽表输入。
- 不设置、不读取 `FORECAST_DATA_ROOT` 和 `WEEKLY_INPUT_CSV`。
- 运行过程中生成的 CSV 只作为 `check_data` / `output` 下的审查快照和模型子进程临时输入，不是部署数据源。

环境解析规则：

- 生产机器优先使用 `/Users/macmini02/miniconda3/envs/forecast_env/bin/python`。
- 本地迁移验证可以显式设置 `PYTHON_BIN=/Users/fengrl/miniconda3/envs/factor-mac/bin/python`。
- 找不到 forecast conda Python，或该 Python 不能 `import pandas` 时会直接失败；不允许静默回退到系统 Python。
- `run_backtest.sh` 与 `run_backtest_test.sh` 启动后会先 `cd` 到项目根目录，避免从不可访问 cwd 继承异常状态。

正式入口默认写 DB。本地测试或迁移验证必须显式设置 `DRY_RUN=1`，或使用默认 dry-run 的 `run_backtest_test.sh`。

## 输出目录

日频、周频按运行日归档；月频按 DB `rdate` 归档，DB `rdate` 为 `feature_month` 的 15 日，真实触发日写入 metadata：

- `check_data/YYYY-MM-DD/raw`
- `check_data/YYYY-MM-DD/model_input`
- `check_data/YYYY-MM-DD/metadata`
- `output/YYYY-MM-DD/prediction`
- `output/YYYY-MM-DD/db_payload`
- `output/YYYY-MM-DD/shap`
- `output/YYYY-MM-DD/backtest`
- `logs/YYYY-MM-DD`
- `hyper_params/YYYY-MM-DD`

## 目标与方向

- 日频：目标为 T+1，标签来自 `target[t+1] / target[t] - 1` 的符号。
- 周频：目标列固定为 `TB1YWI1C/TB5YWI1C/TB0YWI1C`，不是 `WI3C`。
- 月频：只在当月 15 日及之后第一个交易日触发；`feature_month` 为触发日所在月，`target_month=feature_month+1`，写库 `rdate=feature_month` 的 15 日；最终模型为二分类方向。
- 写库方向统一为收益率上涨 `1 -> 空`，收益率下跌 `-1 -> 多`，`0 -> 平`。
